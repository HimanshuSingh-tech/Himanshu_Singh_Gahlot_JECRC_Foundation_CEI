## 📖 About This Repository

This repository is a complete, chronological record of my **8-week industry internship** under the **Celebal Excellence Internship (CEI)** program, completed as part of my academic journey at **JECRC Foundation**.

> 💡 It documents the full learning arc — from writing my first `pandas.DataFrame()` to designing and deploying an end-to-end, production-style **Agentic AI + RAG powered analytics platform**.

### 🌟 What You'll Find Here

- 📓 **Hands-on assignments** covering Python, Statistics, ML, DL, GenAI, RAG, and Agentic AI
- 🧪 **Real-world mini-projects** solved with real datasets, not toy examples
- 🏗️ A **final capstone project — EnergyLens-AI** — combining Machine Learning, FastAPI, and interactive dashboards
- 📈 A visible **learning progression**, week over week, from fundamentals to advanced, agentic AI systems
- 🧭 Clean documentation designed to be **recruiter-friendly** and easy to navigate

This repository isn't just a collection of notebooks — it's a **narrative of growth**, showing how foundational data skills evolved into the ability to design and ship intelligent, AI-driven applications.

### 📖 Project Description

**EnergyLens-AI** is an end-to-end, AI-powered analytics platform built to forecast, segment, and analyze household energy consumption using real-world smart meter data. It combines classical Machine Learning, a production-style **FastAPI** backend, and an interactive web dashboard to deliver actionable, personalized energy insights.

### 📊 Dataset

- **Source:** London Smart Meter Dataset
- Real household-level electricity consumption readings across thousands of London households
- Time-series granularity enabling robust forecasting and behavioral segmentation

### ✨ Key Features

<div align="center">

| Feature | Description |
|:---|:---|
| 🔮 **7-Day Energy Forecasting** | Predicts household energy consumption for the upcoming week using `XGBoost` |
| 🏘️ **Household Segmentation** | Clusters households into behavioral groups using `KMeans` |
| 🚨 **Anomaly Detection** | Flags unusual consumption spikes indicating faults or irregular usage |
| 🎯 **Personalized Recommendations** | Generates tailored energy-saving suggestions per household segment |
| 📊 **Interactive Dashboard** | Real-time visual analytics built with HTML, CSS & JavaScript |
| ⚙️ **FastAPI Backend** | High-performance REST API serving predictions and analytics |
| 🔄 **ML Pipeline** | Automated, reproducible feature engineering and model training pipeline |

</div>

### 🧠 Models Used

<div align="center">

| Model | Purpose |
|:---|:---|
| **XGBoost** | Time-series energy consumption forecasting |
| **KMeans** | Unsupervised household segmentation |
| **Feature Engineering Pipeline** | Lag features, rolling averages, calendar features |
| **StandardScaler** | Feature normalization for clustering & forecasting |

</div>
