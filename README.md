## 🚀 Featured Project — EnergyLens-AI

AI-powered energy consumption analytics platform built on the **London Smart Meter Dataset**.

**Features:** 7-day forecasting (XGBoost) · household segmentation (KMeans) · anomaly detection · personalized recommendations · interactive dashboard

```
Data → Preprocessing → [XGBoost | KMeans | Anomaly Detection] → FastAPI → Dashboard
```

**Stack:** Python · Pandas/NumPy · Scikit-Learn · XGBoost · FastAPI · HTML/CSS/JS
