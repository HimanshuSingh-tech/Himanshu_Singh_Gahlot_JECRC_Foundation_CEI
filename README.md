## 🚀 Final Project — EnergyLens-AI

An AI-powered platform that forecasts and analyzes household energy usage using the **London Smart Meter Dataset**.

**What it does:**
- 🔮 7-day energy forecasting (XGBoost)
- 🏘️ Household segmentation (KMeans)
- 🚨 Anomaly detection
- 📊 Interactive dashboard (FastAPI backend + HTML/CSS/JS frontend)
