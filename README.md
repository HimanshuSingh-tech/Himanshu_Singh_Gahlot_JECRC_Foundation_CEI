## 📖 About
This repo holds all 8 weekly assignments and the final capstone project from my Celebal Excellence Internship — going from Python basics to building an agentic AI pipeline and a full AI-powered web app.

---

## 📅 Week-by-Week

| Week | Topic | What I Built |
|:---:|:---|:---|
| 1 | Python | NumPy/Pandas/stats assignment — arrays, dataframes, hypothesis testing, PCA/SVD, Bayes' theorem, CLT |
| 2 | Classical ML | Regression on a Tesla deliveries dataset (Linear Reg vs Random Forest) + ARIMA time-series forecasting |
| 3 | Classification | Unsupervised country segmentation — K-Means & DBSCAN clustering with PCA visualization on socio-economic data |
| 4 | Intro to Deep Learning | ANN vs CNN on CIFAR-10, with dropout, batch norm, and data augmentation experiments |
| 5 | RNN | Text generation comparing Vanilla RNN, LSTM, and GRU on the same corpus |
| 6 | AE and GAN | Denoising autoencoder on MNIST — removes Gaussian noise from images |
| 7 | RAG and LLMs | Document Q&A system — chunking, FAISS + BM25 hybrid retrieval, cross-encoder re-ranking, answer generation with Qwen2.5 |
| 8 | Agentic AI | Single-agent pipeline that routes queries to a calculator or keyword extractor and returns structured JSON |

**Final Project:** [`Final-Project/EnergyLens`](./Final-Project/EnergyLens) — an AI-powered energy analytics platform on the London Smart Meter dataset, covering forecasting (XGBoost), household segmentation (KMeans), anomaly detection, and a FastAPI + HTML/CSS/JS dashboard.
